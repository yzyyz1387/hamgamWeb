# 插件系统回归清单

每次改动宿主页面、插件运行时、权限过滤、生命周期或模板系统后，都至少过一遍下面这份清单。

## 一、插件中心

- [ ] `/admin/plugins` 能正常打开
- [ ] 已安装插件列表能正常显示
- [ ] 插件启用 / 停用后不报错
- [ ] 插件配置保存后能重新读取
- [ ] 恢复默认配置正常
- [ ] 生命周期区能正常显示
- [ ] 宿主兼容性区不报字段错误

## 二、后台总览

- [ ] 后台总览能正常打开
- [ ] 插件 widgets 能正常渲染
- [ ] 后台顶部快捷区能正常显示插件入口
- [ ] 插件停用后快捷入口自动消失
- [ ] 系统日志区能正常加载

## 三、通知模板系统

- [ ] `/admin/notifications` 能正常打开
- [ ] 模板画廊能正常显示
- [ ] 按模板分类分组正确
- [ ] 套用模板后标题 / 内容填充正确
- [ ] 模板变量替换正常
- [ ] 发送通知后无权限报错

## 四、审核动作系统

### 投稿审核页
- [ ] `/admin/submissions` 能正常打开
- [ ] 勾选多项后批量动作栏正常显示
- [ ] 主动作按钮能执行
- [ ] 更多动作菜单能展开
- [ ] 动作 summary / group 显示正常
- [ ] 插件停用后对应动作自动消失

### 呼号审核页
- [ ] `/admin/callsign` 能正常打开
- [ ] 勾选多项后批量动作栏正常显示
- [ ] 批量复制 / 查看概况动作正常
- [ ] 插件配置关闭后动作不再显示

## 五、资料页扩展

- [ ] 个人资料页插件面板正常
- [ ] 公开资料页插件面板正常
- [ ] 图片列表与用户列表扩展未丢失

## 六、权限与角色

- [ ] SUPER_ADMIN 能看到全部插件管理入口
- [ ] REVIEWER 只能看到被授权入口
- [ ] USER 看不到后台插件能力

## 七、数据库兼容

- [ ] `plugins` 表缺少生命周期扩展列时不报错
- [ ] `audit_logs` 能正常写入
- [ ] `notifications` 能正常写入
